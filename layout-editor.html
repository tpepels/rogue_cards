How to save your work

All 193 cards are editable. The 139 core designs have saved custom layouts; the 54 expansion designs start with their standard positions until you adjust them. Your changes autosave in this browser. Choose EXPORT JSON to make a portable backup. Upload that file in ChatGPT and I can commit it to the repository and generate the permanent CSS for every adjusted card at once.

Tip: Use arrow keys for fine positioning (Shift + arrow for 2 mm), or the measurements above. Position and size use physical millimetres; rotation uses degrees, and layer controls which cutout sits on top. All values work in print.

Rotation and overlap order are saved with each piece. Higher layer numbers sit in front. The image stays behind all paper pieces.

The exported file can be imported here later. It includes every adjusted card, not just the one currently visible.
